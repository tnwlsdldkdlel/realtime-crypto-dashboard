## 1. 디바운스된 재연결이란?

**디바운스(Debounce)**는 연이어 발생하는 이벤트를 그룹화하여 **마지막 이벤트만 처리**하는 기술입니다.

재연결 로직에 이를 적용하면:
> "연결이 끊겼다고 바로 호들갑 떨지 말고, **잠깐(300ms)만 기다려보자.** 만약 그 사이에 다시 연결되면 재연결할 필요 없잖아?"

---

## 2. 왜 필요한가? (문제 상황)

### 상황: "네트워크가 깜빡거려요 (Flapping)"

지하철 와이파이나 불안정한 모바일 네트워크에서는 연결이 1초에도 수십 번씩 붙었다 떨어졌다 할 수 있습니다.

**[디바운스 없을 때]**
1.  `Disconnect` -> 재연결 시도!
2.  (0.1초 뒤) `Connect` -> 성공!
3.  (0.1초 뒤) `Disconnect` -> 으악, 다시 재연결!
4.  **결과**: 소켓을 만들었다 부쉈다 반복하며 **CPU와 배터리 낭비**, 서버에도 **불필요한 부하** 발생.

**[디바운스 있을 때]**
1.  `Disconnect` -> "300ms만 기다려보자." (타이머 시작)
2.  (0.1초 뒤) `Connect` -> "어? 다시 붙었네? 재연결 취소." (타이머 삭제)
3.  **결과**: 아무 일도 안 일어남. **평온함 유지.**

## 3. 지수 백오프와의 차이점

가장 많이 헷갈리는 두 개념의 차이를 명확히 비교해 드립니다.

| 구분 | 디바운스 (Debounce) | 지수 백오프 (Exponential Backoff) |
| :--- | :--- | :--- |
| **목적** | **"성급한 재연결 방지"** | **"서버/네트워크 보호"** |
| **시점** | 연결이 **끊기자마자** (초반 방어선) | 재연결 시도가 **실패했을 때** (후반 방어선) |
| **대기 시간** | 짧고 고정적 (예: 300ms) | 점점 길어짐 (1초 -> 2초 -> 4초...) |
| **비유** | "진짜 끊긴 거 맞아? 3초만 세볼게." | "안 되네... 좀 쉬었다가 다시 해보자." |

> **결론**: 둘은 경쟁 관계가 아니라 **상호 보완 관계**입니다.
> 1.  먼저 **디바운스**로 잽(Jab) 같은 깜빡임을 걸러내고,
> 2.  진짜 끊겨서 재연결을 시도했는데 실패하면 **지수 백오프**로 대기 시간을 늘립니다.

## 4. 실전 구현 코드 (TypeScript)

이 프로젝트(`realtime-crypto-dashboard`)의 `useBinanceWebSocket` 훅에 적용된 패턴입니다.

```typescript
// hooks/useBinanceWebSocket.ts

const reconnectTimerRef = useRef<NodeJS.Timeout | null>(null);

const connect = useCallback(() => {
  // ... 연결 로직 ...
  
  ws.onclose = () => {
    // 1. 기존에 예약된 재연결이 있으면 취소 (중복 방지)
    if (reconnectTimerRef.current) {
      clearTimeout(reconnectTimerRef.current);
    }

    // 2. 디바운스 적용: 300ms 뒤에 재연결 시도
    reconnectTimerRef.current = setTimeout(() => {
      console.log('300ms 지남. 진짜 재연결 시도!');
      connect(); // 실제 재연결 함수 호출
    }, 300); // 300ms 딜레이
  };
  
  ws.onopen = () => {
    // 3. 연결 성공하면 예약된 재연결 취소
    if (reconnectTimerRef.current) {
      clearTimeout(reconnectTimerRef.current);
      reconnectTimerRef.current = null;
    }
  };
}, []);
```

## 5. 핵심 요약

1.  **디바운스**: "잠깐 끊긴 건 무시하자." (단기적 깜빡임 방지)
2.  **지수 백오프**: "계속 안 되면 천천히 하자." (장기적 장애 대응)
3.  **함께 쓰세요**: 디바운스로 1차 필터링 -> 지수 백오프로 2차 안정성 확보. 이것이 **가장 견고한 재연결 전략**입니다.
